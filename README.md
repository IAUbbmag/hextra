A customized redesign of the Hextra theme for the **[Bit & Byte](https://bbmag.ir/en)** student tech magazine. This version focuses on multilingual content support, streamlined article and staff management, and dynamic contributor data extraction.

## ✨ Features

- 📚 **Journal Issues Page**  
  Beautifully designed listing and detail pages for each magazine issue, tailored for clarity and responsiveness.

- 👥 **Staff Directory**  
  Dedicated profile pages for each team member, including name, role(s), photo, and dynamic contributions listing.

- 🔄 **Automatic Contributor Integration**  
  - Automatically displays contributor info (name, role) on each article based on front matter data.  
  - Each role is translated via `i18n` and reflected in both issue pages and staff profiles.

- 🌐 **Multilingual Support**  
  Fully supports both Persian (`fa`) and English (`en`) content.

- 💅 **Modern Design with Tailwind CSS**  
  Responsive, accessible, and clean interface following modern UI/UX best practices.
